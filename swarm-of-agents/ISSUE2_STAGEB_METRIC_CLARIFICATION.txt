- affected_pairs_responded: responses by agents in the event's initial affected_agent set

- successful_responses_among_affected_pairs: successful responses within the initial affected set
- successful_responses_outside_initial_affected_set: successful responses outside that set
- successful_responses: all successful event-linked responses

- agents_became_aware
- agents_responded
